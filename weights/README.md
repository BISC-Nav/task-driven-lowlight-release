# Pretrained models

Obtain pretrained weights from the download instructions in the providers' repositories:

- [DarkSLAM-EnlightenGAN](https://github.com/arsenyinfo/EnlightenGAN-inference#readme)
- [URRE-Net](https://github.com/Chenxy875/URRE-Net#readme)
- [DROID-SLAM](https://github.com/princeton-vl/DROID-SLAM#readme)
- [Zero-DCE](https://github.com/Li-Chongyi/Zero-DCE#readme)
- [SCI](https://github.com/vis-opt-group/SCI#readme)
- [AirSLAM](https://github.com/sair-lab/AirSLAM#readme)
- [Retinexformer](https://github.com/caiyuanhao1998/Retinexformer#readme)
- [RetinexNet](https://github.com/weichen582/RetinexNet#readme)
- [KinD](https://github.com/zhangyhuaee/KinD#readme)
- [SNR-Aware](https://github.com/JIA-Lab-research/SNR-Aware-Low-Light-Enhance#readme)

CLAHE has no learned weights. ORB-based integrations use the vocabulary supplied by ORB-SLAM; see the corresponding source README. The files themselves are not mirrored here. Follow each provider's model and dataset terms.
